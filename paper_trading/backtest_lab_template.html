How this works

Every trade shown here really happened in a backtest against real historical 1-minute or 5-minute bars (NQ, ES, YM, RTY, GC, or CL futures) - fixed at 1 contract, using this project's tested backtest engine. Nothing here re-simulates strategy logic in the browser; the equity curve is reconstructed from those real trades with plain arithmetic (starting balance + realized P&L from closed trades + mark-to-market P&L on whatever's open right now).

Up to 50 real parameter combinations per strategy, drawn from the site's real 18-strategy library - each one's hardcoded defaults plus its own documented PARAM_SPACE's full grid (the same ranges the parameter-sensitivity sweeps already test - nothing invented to hit a round number, so a strategy with only, say, 6 real documented combinations runs 6, not 50). The Leaderboard ranks every one of them, on every track. Only the standouts - each strategy's defaults and extremes, plus whatever lands in the top 10 by return or Sharpe on a given track - get a full interactive chart; the rest are metrics-only rows so the page doesn't have to ship tens of thousands of trades nobody will look at. None of these are validated as statistically significant on intraday data - see the Learn page and Robustness tables before trusting any single result here.

The drawdown simulation is an approximation of prop-firm-style trailing drawdown rules (like Apex Trader Funding's), not a copy of any specific firm's exact terms - "intraday" ratchets the floor up on every new bar-close equity high (including open, unrealized gains), "end-of-day" only ratchets once per session close, and "static" never moves. Verify your actual account's real rules before relying on this for anything but research.
